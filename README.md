# ClosetCloud

A personal digital wardrobe and outfit planner: upload your clothes, build outfits, plan what to wear, and find new ways to style what you already own.

> 🚧 Work in progress — being built phase by phase. Full setup, architecture and screenshots will be documented as features land.

## Tech stack

- **Frontend:** React + Vite, React Router, CSS Modules
- **Backend:** Node.js, Express, REST API _(coming soon)_
- **Database:** PostgreSQL with Prisma _(coming soon)_

## Running the frontend locally

```bash
cd client
npm install
npm run dev
```

Then open http://localhost:5180.
